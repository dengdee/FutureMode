# Proximate 評選展示影片

這是以 Remotion 製作的 2 分鐘產品展示／評選影片，內容涵蓋：

- 會前議前討論與 AI Agent 對話
- 會議中的即時協作與 AI 舉手
- 缺席代理、LLM 文字生成與語音流程
- 文件 chunks、embedding 與 RAG 團隊記憶
- 最後以產品價值、AI 協作、流程完整度與展示潛力收尾評選

## 執行

```bash
npm install
npm run dev
npm run render
```


輸出影片會位於 `out/proximate-showcase.mp4`，封面圖位於 `out/cover.png`。
